Findings on the existing files (not edited, for the conductor):
- `A.param:212-213` BATT_VOLT_MULT 11.05 / BATT_AMP_PERVLT 64 are not the Kakute H743-Wing values (18.18 / 36.36, Holybro Power Monitor page below). `A.param:10` says they are K09-L CoreWing values. They must be re-set for whichever board is chosen.
- `A.param:190` ARSPD_BUS 0; Holybro's H743-Wing mapping page says the I2C2 "I2C port" airspeed bus is ARSPD_BUS = 2. Check at bench.
- `A.param:229` SERIAL6 = RC matches the H743-Wing (SERIAL6 = USART6 RC input, Holybro mapping page). It does NOT match the F405 boards below (RC UART is SERIAL1 on SpeedyBee, SERIAL3 on KakuteF4-Wing).
- Current sensor range: H743-Wing is "90 A continuous / 220 A peak" (RMRC page); its page "range" was "—" in `TEST-PLAN-O4B.md:246`, now answered below.

They lose scripting only, which is no longer needed (D-256).
