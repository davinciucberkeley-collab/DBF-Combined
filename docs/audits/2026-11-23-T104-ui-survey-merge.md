## Where the passes disagreed (later choice kept)
1. **Fonts.** Survey: Barlow Semi Condensed / Source Sans 3 / Red Hat Mono (the `docs/reference/REVIEW-STYLE.md` pairing).
   Explorer redesign 2026-11-16 (`explorer.css`): Newsreader titles, IBM Plex Sans text, IBM Plex Mono for ids. Kept Plex + Newsreader;
   reverted the survey's font tokens in `tokens.css` and `site.css` (`--font-head` now a Plex stack; `.sh-t` uses `--font-display`).
   **Open decision for the conductor:** REVIEW-STYLE.md names the survey faces; switching means editing the `explorer.css` tokens and the font link.
2. **In-page contents.** Survey: `details.otp` list built by `site.js`. v1: the `.rail` "On this page". Kept the rail; removed the survey list,
   its CSS and the `--vn` numbering logic in JS. `site.js` now only adds "#" permalinks to `h2.sh-t` (the rail label excludes the "#").
3. **Top bar.** Survey: tabs with underline, "Design: PROPOSED" status. v1: menu button, brand, side navigation with the status badge in the nav footer. Kept v1; the survey's top-bar CSS was removed.
4. **Title sizes.** Survey 26 / 22 px; v1 (explorer scale) 40 / 28 px. Kept the v1 scale (`h1.sh-t` = `--text-2xl`, `h2.sh-t` = `--text-xl`).
5. **Table and concept-card clipping.** Survey set `overflow: visible` on `.ds-table`, `.ds-trade` and `.ds-concept`; that made the Decision page 2090 px wide
   at 1280 px (card contents overflow). Kept v1's `overflow: hidden` on both.
6. Section numbers (`2.1`, `2.2`, ...) kept, mapped to the current nav order (Aircraft 1 ... Docs 11) in the `--vn` rules of `app.css`.
