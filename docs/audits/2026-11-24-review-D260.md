## Fixes (apply before the next commit)
1. `gen_params_a.py` `cn_beta`: change source from `SRC-A-AR015` to a source that exists for this work (register a `SRC-A-LATDIR` pointing at `sitl/latdir_a.py` and `latdir_a_18.json`), or cite the file in the note only.
2. Wording "fins + wing 0.233" (D-260, A-P15 row, gen_params note): the plant's wing contributes no side force or Cn_beta, so 0.233 is the fins alone (hand check 0.236). Say "fins (the model has no wing Cn_beta)".
3. Sensitivity: the plant puts no roll arm on the fin side force (Cl_beta = CLB x f only) and omits the induced-drag part of wing Cn_r. Add one sentence to D-260 that these are omitted, with the bound: the conclusion stays divergent unless Cl_beta reaches about -0.24 (about 6x the EST -0.04) or |Cn_r| roughly doubles with Cl_beta unchanged would still need Cl_beta below -0.12. Fin side force Cy_beta -1.19 acting at a z offset of 0.1 m would add only about 0.13 to |Cl_beta|, so it does not flip the sign, but state that it was not modelled. The "-0.24" is a bare-airframe approximation (Cy and Cn_p, Cl_p terms ignored); the eigenvalue confirms the sign.
4. State the severity honestly: 2.4 to 2.8 s doubling is worse than the MIL-F-8785C Class I Level 3 spiral limit (4 s) that I recall, but I did not open that standard, so this is unverified. Either cite it (opened) or drop the comparison; either way keep the "roll loop failure or GCS mode outside the switch" residual, and also name ArduPilot's own failsafe mode changes as a mode path outside the switch.

Low priority.
6. Docstring: cite a source (or say "textbook, not opened") for Cn_p = -CL/8.
7. Estimates: CLB -0.04, CLAF 2.5, Ixz 0 are all labelled EST ("—" for Ixz in the script docstring and D-260); Ixz is unknown (cad_mass.json has no product of inertia), and with Ixz 0 the Dutch-roll and spiral values are approximate. No overclaim found; keep the EST tags on the A-P15 row.
