# D12. Nautical Wings prop spec sheet

**Recommendation:** Re-base the spec sheet on the 11-02 sizing before it goes out: lift hover 18.2 N (1.86 kg) per rotor with peak thrust at or above 29.2 N (2.98 kg, the R13 T/W 1.6 floor; baseline prop gives 30.7 N), pusher 8.4 N at 18 m/s, and one quantity everywhere: 6 lift props (3 CW + 3 CCW) and 2 pusher props.

**Confidence:** High on the arithmetic and on the quantity fix (all inputs are in repo files). Medium on whether the design point stays valid, because it moves if D1, D2 or D3 change.

**Depends on:** D1 (assumed: 11-02 baseline, MTOW 7.438 kg), D2 (assumed: 18 m/s cruise), D3 (MTOW/wing). If D1 or D2 reverts to v0.3.1 (6.182 kg, 20 m/s), use the fallback column below. The NWA sponsorship itself is still only verbal (team-reported).

## Reasoning

### Verified facts
- `analysis/results.json` `concepts.C0.sized`: m = 7.4379985 kg, Tunit_g = 1859.48 g per lift unit (hover), TW = 1.683, D_cruise = 8.3762 N at Vc = 18 m/s. `params.Tmax_g` = 3130 g per motor (maker's 22.2 V table), `params.liftD` = 0.4318 m (17 in).
- `docs/DESIGN-BASIS.md` R13: hover T/W >= 1.6 at MTOW on the maker's 22.2 V thrust table. Line 54 states hover T/W 1.68.
- The research note (`docs/research/nautical-wings-props.md` line 29, "Design point" row) uses 6.18 kg / 4 = 1.545 kg = 15.2 N and "Cruise at 20 m/s". That is the v0.3.1 value. It cites `../DESIGN-BASIS.md`, which now says 7.438 kg.
- The same stale 15.2 N is hard-coded in `inventory/build_overview.mjs` line 318 (`HOVER_N: '15.2'`) and in `inventory/build_inventory.mjs` line 120 (N-01 note "hover point 15.2 N per rotor"). It therefore reaches `inventory/inventory.json`, `inventory.csv`, `DBF-Inventory-sheet.csv` and `Inventory-Overview.html` (N-01 row).
- `NWA_MSG` (build_overview.mjs lines 275-298) gives no numeric design point, only "hover design point" attached. It builds its counts from the N-01/N-02 rows ("2 CW + 2 CCW + 2 spare" -> "2 clockwise, 2 counter-clockwise and 2 spares"; N-02 qty 2). The message is internally consistent with N-01 (6 + 2) but not with the spec sheet.
- BOM (`docs/purchasing/C0_BOM.csv` lines 34, 36): JeeFly 1755 pair x2 plus a spare pair x1 = 6 props. Pusher: APC 14x8.5EP x3 (line 42).

### Lift design point (per rotor)
| Quantity | Calc | Value |
|---|---|---|
| MTOW | results.json sized.m | 7.438 kg (72.94 N) |
| Hover thrust per rotor | 7.438 / 4 = 1.8595 kg x 9.80665 | **1.86 kg = 18.2 N** (matches Tunit_g 1859.5) |
| Old (v0.3.1) value | 6.18 / 4 | 1.545 kg = 15.2 N, understated by 17 % |
| Peak at T/W 1.6 (R13 minimum) | 1.6 x 18.24 N | **29.2 N = 2.98 kg** per rotor |
| Peak the baseline prop provides | Tmax_g 3130 g (T/W 1.683) | 30.7 N = 3.13 kg |
| Old "+50 % control margin" | 1.5 x 1.86 kg | 2.79 kg, which is T/W 1.50 and fails R13. Do not use it. |

Disc area is 0.1464 m^2 per rotor, disc loading 124.5 N/m^2 (results.json sized). Ask the designer to quote thrust and RPM on the 22.2 V nominal point so it compares with the maker's table used by R13. Air density in the analysis is 1.225 kg/m^3 (sea level, 15 C). At the R21 25 C ceiling it is about 1.18 (3 % lower), which is a small extra thrust loss to mention but not to design around.

### Pusher design point
Cruise thrust equals drag: **8.38 N (0.854 kgf) at 18 m/s** (sized D_cruise 8.3762 N; the unsized design pass gives 8.25 N, so use the sized value). Thrust power 8.376 x 18 = 150.8 W. The analysis assumes etaProp 0.6, so shaft power is about 251 W and electrical cruise power is 295.6 W (P_cruise). Fallback if cruise reverts to 20 m/s: the repo has no 11-02 drag at 20 m/s in results.json; scale roughly with drag, but take it from `analysis/cruise_speed_trade.json` rather than estimating. Static or climb-out thrust for the pusher is not given in the repo; the spec asks the designer to report static thrust and leaves the requirement open (no number invented).

### Quantity inconsistency
Cause: the spec sheet counts motors (5 motors), the message and N-01 count props (6), and the BOM counts pairs. The header "x4 + 1 spare" = 5 props, "a spare of each direction" = 6, "6 min" = 6. Props come in pairs, so a CW spare alone is not useful.

Resolution: **6 lift props = 3 CW + 3 CCW (4 flying + 1 spare CW + 1 spare CCW)** and **2 pusher props (1 flying + 1 spare)**. This matches N-01 (qty 6), N-02 (qty 2), the BOM's 6 JeeFly props, and the message. The "5 motors" remark in the Rotation row is wrong for props; the fifth lift-size motor does not exist (4 lift motors + 1 pusher motor, with one spare X4110S P-40 proposed). Remove it. Note the N-01 item text "2 CW + 2 CCW + 2 spare" is ambiguous (reads as 2 spare of either hand); change to "3 CW + 3 CCW (incl. 1 spare each)". The message builder's regex reads that text (`spl()` matches "(\d+) CW \+ (\d+) CCW \+ (\d+) spare"), so the wording and the regex must change together.

## Risks / what would change the call
- D1/D3: any change in MTOW rescales the lift row (thrust per rotor = MTOW/4 x 9.81; peak = 1.6 x that). Fallback v0.3.1 values: 15.2 N hover, 24.3 N peak at T/W 1.6, pusher drag from `inventory/v031/analysis/results.json` at 20 m/s.
- D2: pusher thrust follows drag at the chosen speed; 18 vs 20 m/s changes the pusher row only.
- The peak requirement of 29.2 N is the R13 floor on the maker's table; the 17x5.5 baseline is 5 % above it. A custom prop that cannot reach 29.2 N at the 25.2 V cell limit and 26 A/30 s would fail R13 and should be rejected, not just flagged.
- 17 in is beyond the retailer's recommended 12-15 in prop range for the X4110S (research note line 22); the designer must confirm max RPM and current with that motor. At no-load 10,080 RPM a 17 in tip speed is about 228 m/s (Mach 0.67), so tip Mach is not the limiting factor.
- The sponsorship is verbal; a spec sheet with numbers should not imply a commitment.
