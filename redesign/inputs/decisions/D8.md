# D8. GPS: RMRC SAM-M10Q-5883 ($24.99) or HGLRC M100-5883 ($20.49)

**Recommendation:** Keep the RMRC SAM-M10Q-5883 ($24.99): it ships with a ready-made JST-SH 6-pin cable, is in stock, and the ReadyMadeRC order ships free either way, so the $4.50 "saving" from HGLRC would be eaten by a separate RaceDayQuads parcel.

**Confidence:** medium. The cost and shipping logic is solid. The compass chip is unnamed on both listings ("5883-series"), and the CoreWing GPS connector type and pin order were not found in any page I could read, so the cable fit is unverified for both options.

**Depends on:** D1 baseline FC stays the CoreWing F405 Wing V2 (BOM line 4). If the FC flips to the Kakute H743-Wing fallback, re-check the connector, but the GPS choice would not change (both modules offer UART + I2C). D5-D7 assumed to keep the ReadyMadeRC consolidation (airspeed, receiver, servos, FC, BeeID stay on RMRC).

**Reasoning:**
- Current state: BOM has the RMRC part (`docs/purchasing/C0_BOM.csv` line 5, $24.99); `firmware/vtol_c0.param` line 200 comment names it; the older HGLRC is in `inventory/v031/docs/purchasing/C0_BOM.csv` line 34 ($20.49, RaceDayQuads).
- Chipset: both are u-blox M10. RMRC page lists u-blox M10 (GPS, GLONASS, Galileo, BeiDou, SBAS, QZSS), 10 Hz (https://www.readymaderc.com/products/details/86750-rmrc-gps-and-compass-module-m10q-5883, retailer page). HGLRC listings say u-blox M10, 10 Hz, 115200 baud UBX (retailer listings: Walmart/Amazon/RDQ via search; constellation list differs between listings). Equivalent for our use; ArduPilot auto-detects u-blox M10 over UBX (GPS_TYPE auto default). Not verified on hardware for either.
- Compass: RMRC says "5883-series digital magnetometer", no part number. HGLRC retailer listings and manual say QMC5883. Likely the same QMC5883L-class part on both; ArduPilot supports QMC5883L on external I2C with auto-probe. The repo already flags the compass chip as unknown (`docs/research/electrical-architecture.md` lines 77, 106). Judgement: treat as equal; the compass is the less-trusted sensor either way, calibrate and check interference per `firmware/README.md` 6.3/6.3a (pack trunk about 65 mm from the GPS).
- Connector: RMRC page lists a 6-pin JST-SH 1.0 mm port (TX, RX, GND, 5V, SCL, SDA) plus solder pads, with a 6-pin-to-6-pin SH cable and an SH-to-pin-header harness included. HGLRC pins are SCL, SDA, RX, TX, 5V, GND with a "connecting cable" of unstated type, and its manual says to solder to the wiring diagram. The ArduPilot CoreWing page confirms the FC GPS connector carries UART5 + I2C + 4V5 and that the connector pin order differs from the solder pads (https://ardupilot.org/plane/docs/common-CoreWingF405WingV2.html, manufacturer-doc), but does not state connector type/pin order. `firmware/README.md` line 88 already warns about this. RMRC gives the more plug-in-ready path if the FC connector is SH 6-pin (judgement, not verified); if pin order differs, the included pin-header harness lets us re-pin.
- Vendor order: RMRC order total is $392.05 (67.18 + 24.99 + 39.99 + 76.99 + 22.96 + 59.99 + 99.95; arithmetic). Free-shipping rule is cheapest rate under 5 % of total (`docs/research/bom-savings.md` line 75): limit $19.60; quoted rates $6.49-$14.99, so free. Without the GPS the order is $367.06, limit $18.35, which is still above the highest quote of $14.99, so it still ships free. Conclusion: dropping the GPS from RMRC does not change RMRC shipping. Switching to HGLRC means a separate RDQ parcel for a $20.49 item, far under RDQ's $199 free threshold (bom-savings.md line 96); only RDQ shipping figure in the repo is $6.49 (line 74). Net: $20.49 + about $6.49 = about $26.98 versus $24.99, before tax. HGLRC is cheaper only if bundled into another RDQ order, and nothing else in the BOM comes from RDQ now (BeeID is out of stock there).
- Backorder note: RMRC holds the whole order until the FC and RP3 arrive (bom-savings.md line 113). The GPS in stock adds no delay. A separate HGLRC order would arrive early but adds nothing.

**Risks / what would change the call:**
- Compass chip is not named by RMRC; if the unit arrives with a non-QMC5883L part or a bad compass, ArduPilot may not auto-probe it. Mitigation: bench-test on receipt (GPS lock, compass appears in Mission Planner), within RMRC's return policy.
- RMRC SAM-M10Q-5883 is a store-brand listing with a thin page; a "Matek SAM-M10Q" sibling page is discontinued, so stock could vanish. Fallbacks: Foxeer M10Q-5883 (RMRC/Pyrodrone), HGLRC M100-5883 from RDQ at $20.49 (in stock per `docs/research/budget-avionics.md` line 157).
- Flip to HGLRC only if RMRC drops the GPS from stock or the RMRC order is cancelled/split for another reason (then GPS would ride in an RDQ or other order at no extra shipping).
- Verify the CoreWing GPS connector on the physical board; if it is SH 6-pin, RMRC cable fits straight in. Do not plug anything until pin order is confirmed (CoreWing manual warns of damaging mismatches).
