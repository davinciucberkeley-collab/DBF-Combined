Rules: one parameter change per flight; every change logged with the log number in `team/F4/sitl/RESULTS.md` or the
flight log; the parameter file is re-saved and re-checked (`python -I redesign/team/F4/fsw_check.py`) after each
session. Gains above the step-4 ceilings or `THR_MAX` above 60 need a new F4 revision, not a field change.

D-128's 40 % differential (`ASM-B3-GUST-DIFF-MAX`) is an analysis allowance for the 8 m/s hover gust only, not for transition. No
ArduPilot parameter caps the per-axis differential; the mixer gives roll / pitch priority over yaw. Nothing is set for it.
