# K09-L critical design review: aerodynamics, stability and control, propulsion, performance

Reviewer: J6-aero (CDR board), 2026-11-13, branch `redesign/v1` at `39d52a2`.
Scope: `team/B1`–`B4`, `team/E1`, `team/E2`, the motor rows of `team/E3`, `subsystems/propulsion/`, and
`subsystems/flight-software/` where it sets control behaviour.
Method: read every SUMMARY, report, SPEC and `claims*.json` in scope; read `proofs/out/CHAIN.md` for failures; checked
the numbers chain by hand and with a 60-line motor/prop script on the team's own equations and data; compared against
the motor maker's table, APC PER3 files and ArduPilot pages (URLs at the end, all checked 2026-11-13). No team script
was run inside the tree: a trial run of `team/E1/propulsion.py` in a scratch copy showed it calls
`team/C6/fastener_parts.py`, which rewrites `subsystems/*/parts.csv` (CDR-AE-13). No file other than this one was
edited. Nothing in scope is tested, so "passes" means "passes on paper". My own arithmetic is labelled `REVIEWER EST`.

## Verdict

**Go with conditions** for the 15 December order. No finding needs a different configuration, motor count or wing.

The chain is internally consistent and mostly conservative where I could check it (table "Checks that held"). It is
not a clean go for four reasons. Each can be settled with the early cart (about 20 November) and the twin, before
15 December.
