# C4 fin / motor-tube structures: design round 2026-11-14, wave 2

Role C4. Brief: `A1.md` §3 (analysts row), D-146 and D-147. Geometry is D3's R6 (`D3-W2.md`): 9° cant,
`face_ahead` 12.0 mm, cheeks 21.5 mm, tube OD 22.10 / ID 19.05 mm. Loads are C1's 9° / 12 mm set (`C1-W2.md`).
Rotor speeds are B4's wave-2 claims (`B4-W2.md`). I edited only `team/C4/`. I did not run git, `proofs/build_graph.py`
or any shared gate.

**Verdict.** `CL-C4-SIM-SEP` (R-VIBRATION) now passes: **0.145 → 0.244**, against ≥ 0.20. Every fin, collar,
anchor, brace and mount margin still passes. The separation is lower than the 0.322 I predicted in wave 1. That is
not because of the tube. D-145 raised the cruise rpm (`CL-B4-CRUISE-RPM` 5 994 → 6 347), which moves 2P cruise from
199.8 to **211.6 Hz**. The first station mode, 263.3 Hz, now sits 3.7 % above the 253.9 Hz the rule needs (1.2 × 211.6).
**At the knock-down tube properties (E 78.6 / G 10.3 GPa) the separation is 0.189, which fails.** It is an
information row, but it means the delivered tube's measured E and G now decide this requirement (§4).

needs about f1 ≥ 253.9 Hz. The 3-D model gives 263.3 Hz at the page values and 251.6 Hz at the knock-down. The pass
line lies about one fifth of the way from the knock-down toward the page values (`EST`, linear in f1). The shell pass lines (§3:
E ≥ 65.7 GPa at G 20.5, G ≥ 8.67 GPa at E 90.2) are what the GT-16 card should test against now.

## 5. Requests and open items

1. **H1 (GT-16 card), replaces C4 R4.** The pass lines are now **E ≥ 65.7 GPa (at G 20.5)** and **G ≥ 8.67 GPa (at
   E 90.2)** (`CL-C4-D3-TUBE-E-REQ` / `-G-REQ`). Wave 1 gave 37.5 / 3.96 GPa, which assumed the 15.6 m/s cruise.
   Measure both on a delivered tube before the fins are printed. If either reads below the line, re-run
   `sim_fin.py` with the measured values before the first hover.
2. **A1 (params notes only).** The `fins.tube.e_gpa` note says "knock-down case at 78.6 GPa (separation 0.289)"
   → "0.189 at 17 m/s cruise rpm (C4-W2 §4)". The `g_gpa` note says "Shell-model pass lines at 9 deg / 12 mm:
   E >= 37.5, G >= 3.96 GPa" → "E >= 65.7, G >= 8.67 GPa (C4-W2)". No value changes.
3. **A3.** `CL-C4-D3-FINS-MASS` 476.1 g against the 471 g allocation, the same 5.1 g as D3's `CL-D3-MASS` request.
4. **Open: tube strength allowable.** `CL-C4-D3-MS-TUBE` uses `ASM-C4-CF-SIGMA` 400 MPa, the roll-wrapped UD
   value. The 35046-S page lists no strength (`C4.md` §1.2), so its ±15 / hoop / ±45 / ±15 axial strength is "—".
   The margin is 13.1, so even a 400 → 100 MPa knock-down leaves MS ≈ +2.5 (`EST`, linear). Strength is not
   at risk, but the allowable has no source for this tube. Proposed for GT-16: one bend-to-failure on the spare
   48 in offcut.
5. **Open: B4's misbuilt-swirl bound.** `CR-B4-19` (1.43 N) was not re-run at 9° (`B4-W2.md` W2-B4-4). C4 still
   uses the old bound, which is conservative.
6. **Rpm dependence.** A higher cruise rpm takes away separation one for one. Any further cruise speed increase above
   17 m/s, or a prop change, re-opens `CL-C4-SIM-SEP`. The limit is 2P cruise ≤ 263.3 / 1.2 = 219.4 Hz, that
   is cruise ≤ **6 582 rpm** (`EST`, from the extrapolated f1).
